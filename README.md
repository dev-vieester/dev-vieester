## Models & ML Experiments

I work across both model fundamentals and model-powered applications. These repositories document hands-on experiments and integrations—not claims of training large foundation models from scratch.

### Building blocks and small models

- [Micrograd](https://github.com/dev-vieester/Micrograd) — Implemented a compact automatic-differentiation engine with computation graphs and backpropagation, then used it to explore neuron, layer, and multilayer-perceptron building blocks.
- [classification_neural_network](https://github.com/dev-vieester/classification_neural_network) — Built and trained a small PyTorch feedforward neural network for binary classification on a nonlinear `make_circles` dataset.
- [Bigram](https://github.com/dev-vieester/Bigram) — Explored character-level bigram statistics and transition probabilities for learning patterns in names.
- [Trigram](https://github.com/dev-vieester/Trigram) — Implemented count-based and neural character-level language modeling to predict the next character from a two-character context and generate names.
- [Tokenization](https://github.com/dev-vieester/Tokenization) — Built an educational byte-level Byte Pair Encoding (BPE) tokenizer and trained it on Tiny Shakespeare text.
- [PyTorch_foundation](https://github.com/dev-vieester/PyTorch_foundation) — PyTorch learning and model-building experiments.

### Models used in AI applications

- **Claude (Anthropic)** — Used in research and document-question-answering workflows, including a RAG pipeline that grounds responses in retrieved document context.
- **OpenRouter-served chat models** — IvyGPT is configured to use a selectable model through `OPENROUTER_MODEL`; the specific model depends on project configuration.
- **`all-MiniLM-L6-v2` embeddings** — Used to embed document chunks for semantic retrieval in a local ChromaDB RAG project.
- **Google/Gemini embeddings** — Supported as an optional embedding provider in the Ivy assistant project.
